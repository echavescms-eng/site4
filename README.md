# Vértice Advocacia — site demonstrativo

Projeto acadêmico de site institucional de advocacia desenvolvido com HTML, CSS e JavaScript puro.

## Páginas
- `index.html` — página inicial
- `sobre.html` — apresentação e valores
- `areas.html` — áreas de atuação com filtro por categoria
- `portfolio.html` — itens fictícios com filtro e janela modal
- `contato.html` — formulário com validação e cópia local da mensagem

## Estrutura
```text
site_advocacia/
├── index.html
├── sobre.html
├── areas.html
├── portfolio.html
├── contato.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como abrir no VS Code
1. Baixe e extraia o arquivo ZIP.
2. Abra o Visual Studio Code.
3. Clique em **Arquivo > Abrir Pasta...** e selecione a pasta `site_advocacia`.
4. Abra `index.html`.
5. Para testar, você pode clicar com o botão direito em `index.html` e escolher **Open with Live Server** (se a extensão Live Server estiver instalada). Também é possível abrir `index.html` diretamente no navegador; o site não precisa de servidor para as funções básicas.

## Personalização
- Troque “Vértice Advocacia” pelo nome desejado.
- Substitua e-mail, telefone, endereço e horários em `contato.html`.
- Atualize textos, áreas de atuação e itens do portfólio.
- As imagens de capa usam URLs do Unsplash e precisam de conexão com a internet. Você pode substituí-las por imagens próprias.
- As fontes Playfair Display e DM Sans são carregadas do Google Fonts; se não houver internet, serão usadas fontes alternativas.

## Funcionalidades
- Navegação entre as cinco páginas.
- Menu responsivo para celular.
- Layout adaptável para telas pequenas e grandes.
- Filtro de áreas por categoria.
- Filtro do portfólio por tipo.
- Janela modal para ler resumos demonstrativos.
- Formulário com validação e cópia da mensagem para a área de transferência. O formulário não envia dados para um servidor.

## Importante
Este é um exemplo fictício para fins acadêmicos. Nomes, histórico, eventos, endereço e contatos são demonstrativos. Não representa um escritório real nem oferece orientação jurídica.
